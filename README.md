## 学习路线

```
Java 基础语法 → 面向对象 → 常用 API → 集合框架 → IO 流 → 多线程 → 网络编程 → JVM → 框架
```

- **阶段一**：Java 基础 + 每日一道算法
- **阶段二**：面向对象深入（继承、多态、接口、内部类）
- **阶段三**：集合框架 + 泛型 + 异常处理
- **阶段四**：IO 流 + 多线程 + 网络编程
- **阶段五**：JVM + 设计模式 + 框架入门

## 笔记结构

每篇笔记包含：

- **算法练习**：题目分析、解题思路、代码实现、复杂度分析
- **知识点**：核心概念、代码示例、注意事项、与已有知识的关联
- **每日总结**：当日要点回顾
