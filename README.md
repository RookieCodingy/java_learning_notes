## 学习路线

```
Java 基础 → JavaWeb + AI → 苍穹外卖 → AI + 若依框架 → 微服务 → 黑马头条项目 → 学成在线项目 → Java 大厂面试专题课
```

| 阶段 | 内容 | 目标 |
|------|------|------|
| 一 | Java 基础 | 掌握核心语法与面向对象，每日一道算法 |
| 二 | JavaWeb + AI | Servlet、Spring、数据库，结合 AI 提效开发 |
| 三 | 苍穹外卖 | 实战项目，掌握企业级后端开发全流程 |
| 四 | AI + 若依框架 | 若依框架二次开发，AI 辅助编码 |
| 五 | 微服务 | Spring Cloud、Docker、分布式架构 |
| 六 | 黑马头条项目 | 大规模内容平台实战 |
| 七 | 学成在线项目 | 在线教育平台全栈实战 |
| 八 | Java 大厂面试专题课 | 算法、JVM、并发、框架底层，冲刺大厂 |

## 笔记结构

每篇笔记包含：

- **算法练习**：题目分析、解题思路、代码实现、复杂度分析
- **知识点**：核心概念、代码示例、注意事项、与已有知识的关联
